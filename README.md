# Shade net house: what to list before you ask for a quote

A shade net house is simpler than a polyhouse, but a quote can still miss the parts that matter.

| Item | What to state |
|---|---|
| Net | shade percentage, width, GSM, colour |
| Structure | pipe or pole size, bay spacing, height |
| Fixing | clamps, wire, clips; see [greenhouse fixing](https://www.blustal.com/products/greenhouse-fixing/) |
| Net | choose from the [shade net range](https://www.blustal.com/products/shade-net/) |
| Quantities | use the [polyhouse material list](https://www.blustal.com/polyhouse-material-list/) method and drop the film items |

Quote line by line, in writing. Source: [BLUSTAL](https://www.blustal.com/), Ludhiana, since 2004.
